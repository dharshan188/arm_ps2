# Offline Hindi / Tamil STT candidates

Researched 2026-11-17 for a Raspberry Pi 5 (8 GB, four A76 cores, CPU only).
Download sizes below are decimal MB/GB; RSS is separate. Published WERs use different
datasets and normalization and **do not predict this kiosk's WER**. Runtime estimates
are screening judgments unless explicitly identified as measured. The local report
contains the actual same-set comparison.

**NC terms:** none of the three selected downloads declares noncommercial restrictions.
Do not generalize that to arbitrary community checkpoints. Unspecified licences (e.g.
the Tamil medium CT2 above) are unresolved, not permission for commercial use.

Revisions, exact bytes, source URLs and SHA-256 hashes are saved alongside downloaded
files in `voice/_dl/<name>/download.json`. All inference is local after provisioning.
The evaluated CTC models output native-script loanwords, matching these references;
Romanized Hinglish models would require a separately validated transliteration/scoring path.
